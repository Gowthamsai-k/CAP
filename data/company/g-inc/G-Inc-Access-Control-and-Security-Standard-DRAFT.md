# G Inc Access Control and Security Standard

**Document class:** Synthetic company standard draft — not law  
**Company:** G Inc (fictional)  
**Version:** 0.1 (demo draft)  
**Owner:** Fictional Security Lead  
**Review date:** 2026-11-01  
**Approval status:** Unapproved; created only for software demonstration

> This is a sample set of internal safeguards for a fictional company. It does not establish that any system is secure or legally compliant.

## 1. Identity and access

Use an individual account for each worker. Require multi-factor authentication for administrative and remote access. Grant least-privilege access based on an approved role and documented business need. Prohibit shared administrator accounts except for a documented emergency process with attributable audit records.

## 2. Joiner, mover, and leaver controls

The manager requests access through the approved workflow. System owners approve permissions for systems they own. Managers review access quarterly in this demo standard and after role changes. Disable accounts promptly when employment or a vendor engagement ends and recover company devices and credentials.

## 3. Protection and logging

Use encrypted transport for company services and approved encryption for stored personal data where supported. Store secrets in an approved secrets manager, not source code or shared documents. Log administrative actions and access to sensitive records where feasible; restrict log access and retention. Test backups and recovery periodically.

## 4. Secure handling

Workers must not send personal data to personal email, public AI tools, public code repositories, or unapproved storage. Report suspected exposure or unauthorized access promptly under the incident response procedure. Security exceptions require a documented owner, reason, compensating controls, and expiry date.

## 5. Review and evidence

System owners maintain records of access approvals, periodic reviews, exceptions, and remediation. The Security Lead reviews this draft at least annually or after a material incident or system change. All controls and intervals in this sample remain proposals until approved and implemented by the fictional company.
